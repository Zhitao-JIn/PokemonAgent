# FM-043 跨run经验携带使重复实验不再独立

- 整理日期：2026-10-25（Europe/Berlin）
- 分类：记忆/实验
- 状态：历史风险；取决于实验目的，不能一律叫bug
- 适用边界：本文记录给定版本下的失败模式；历史存在不等于当前仍存在，候选或单次通过不等于稳定修复。

## 现象与触发

后续run读到前面试验积累的经验，能力变化却被算作prompt收益。

## 证据与定位

2026-09-01经验确认历史检索按scene读取全部磁盘摘要，不区分run/批次；memory_carried作为诊断入口提出。

## 根因与确认边界

带学习能力的运行与要求独立重复的实验定义不同；记忆复用本身可能是设计目的。

## 处理方向与取舍

明确实验是纯能力还是带学习，冻结/隔离/记录初始记忆；不要默默清空或默认独立。

## 验收要点

每次run携带记忆规模与来源可见，对照条件一致或明确列出污染限制。
