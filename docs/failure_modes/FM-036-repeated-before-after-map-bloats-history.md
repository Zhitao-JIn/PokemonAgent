# FM-036 历史前后观测反复渲染不变大地图

- 整理日期：2026-10-25（Europe/Berlin）
- 分类：输入/延迟
- 状态：2026-08历史已优化；当前渲染需另审
- 适用边界：本文记录给定版本下的失败模式；历史存在不等于当前仍存在，候选或单次通过不等于稳定修复。

## 现象与触发

审计/判定输入膨胀，收尾调用比决策更慢。

## 证据与定位

2026-08-31经验：单条记忆1300字符，walk_map两份约800占62%；渲染精简后356字符，审计77秒→11.4秒。

## 根因与确认边界

不变环境地图在before/after及多条历史中重复，文字表示冗余。

## 处理方向与取舍

只在渲染层减少重复，原始facts保留；不截断JSON或删除真实证据。

## 验收要点

消费方仍可核对必要变化；输入/时长以真实新trace复核，不能把历史缩减比例当当前收益。
