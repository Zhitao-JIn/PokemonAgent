# FM-049 界面说明文字被计入菜单选项

- 整理日期：2026-10-25（Europe/Berlin）
- 分类：历史观测/判定
- 状态：仅历史经验二级证据；当前未复现
- 适用边界：本文记录给定版本下的失败模式；历史存在不等于当前仍存在，候选或单次通过不等于稳定修复。

## 现象与触发

把“Choose a POKéMON.”一类说明句当作额外可选项，数量或目标位置判断错误。

## 证据与定位

测评框架bootstrap经验将这类误判转成手写回归；旧视觉档后来已删除。

## 根因与确认边界

说明文字、可选项和光标位置没有分层，历史视觉噪声与当前RAM解码不可直接等价。

## 处理方向与取舍

区分指令文本、选项结构、选项数量与光标证据；当前是否有该问题需实际字段验证。

## 验收要点

说明句不改变选项数，真正新增/缺失选项才改变判定；不拿历史噪声宣称当前故障。
