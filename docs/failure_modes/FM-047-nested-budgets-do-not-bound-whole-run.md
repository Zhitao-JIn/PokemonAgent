# FM-047 分层局部预算无法约束全run资源与正常收尾

- 整理日期：2026-10-25（Europe/Berlin）
- 分类：预算/生命周期
- 状态：历史预算方案已改造；父建议语义本次另行更新
- 适用边界：本文记录给定版本下的失败模式；历史存在不等于当前仍存在，候选或单次通过不等于稳定修复。

## 现象与触发

第一局过长，run最多几局不起作用；剩余时间不足仍发起长模型请求，外层600秒只能强杀。

## 证据与定位

旧budget spec商店第六例无run_end、两评分N；单次拆解可等435秒而样本只剩160秒；当时缺累计动作/重拆解/重试剩余时间约束。

## 根因与确认边界

各层单位、累计量与单调deadline未贯穿；局部任务预算不能替代配置全局硬闸。

## 处理方向与取舍

保留配置硬预算、统一deadline与确定性收尾；最新父级建议预算不得再充当硬闸。旧RunBudget/RunConfig API已淘汰，不照抄旧实现名。

## 验收要点

请求/重试/动作前检查资源；到配置硬限可正常结算留账，不以外层强杀作为唯一停止机制。
