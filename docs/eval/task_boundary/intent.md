# intent —— 任务边界怎么写（经验与对照实验）

> 流程位置：**intent.md**（待确认）→ spec → plan

## 一、一句话意图

把"目标文怎么写边界"沉淀成一套可检查的写法，并用同一批任务、同一判据，对比有边界与无边界的目标文对成功率的影响。

## 二、经验：边界由六个要素组成

任务边界不是一句话，而是目标文与 `success_criteria` 里回答六个问题的部分。

| 要素 | 回答什么 | 缺失时的典型后果 | 本项目里的例子 |
|---|---|---|---|
| B1 范围 | 对象是谁、几个、哪些算 | "所有"含不可达对象，判据无法落地；或做一个就收手 | `shop_interaction` 原写"与全部 NPC 对话"，柜台里的店员走不到，后改为"至少两位不同 NPC 各完成一次对话"；另一次 agent 在首位店员售罄后即结束，同屏还有其他人 |
| B2 完成信号 | 看到什么算做完 | agent 与 judge 对"做完"理解不同，judge 假阳 / 假阴 | `movement_obstacle` 写成"走到 y=14 或更南"，而不是"绕过去"；`door_transition` 以 `map_id` 变化为准 |
| B3 停手 | 做完后不要再做什么 | 越界、过冲，多出无意义动作 | `battle_action_menu` 写"移到 RUN 后立即停手，不要按 a，不要新增目标"；`overshoot_scorer` 专门数完成之后多出的动作 |
| B4 约束 | 不许做什么、预算、顺序 | 走了违规捷径，最近的路往往就是违规的路 | M5 的"不要去宝可梦中心""不超过 150"；M2 的"先治后买" |
| B5 放弃条件 | 什么才算真的做不成 | 把资源耗尽或缺一个对象当成世界受阻而放弃 | judge / decompose 提示里补的"资源耗尽不等于世界受阻，单个 NPC 售罄不能排除其他对象" |
| B6 锚点 | 目标里指代的东西从哪确定 | 指代无法解析，或要求 agent 记住没写下来的信息 | M2 的"回到你现在站的这个位置"，锚点只在第一帧；写坐标则变成靠目标文传递，不测记忆 |

**写法规则**

1. 目标文写"要什么"和"到哪停"，不写"怎么走"。路径、坐标、按键序列不进目标文；允许出现的坐标只能是判据本身（如 y ≥ 14）。
2. B2 必须能对应一条机械判据；写不出对应判据的完成信号，不进 `success_criteria`。
3. B1 的数量用"至少 N 个不同对象"这类可核对的说法，不用"全部"，除非冻结时已核实全部可达。
4. B3 只在存在越界风险时写（任务以"停在某个状态"为终点时必写），其余不写，避免目标文变成清单。
5. B4 的否定式约束同时进目标文和 `success_criteria`，并有对应的机械违规检查（如全程无帧 `map_id == 41`）。
6. B5 不写进样本目标文，由 judge / decompose 提示统一承担；样本只在判据里保证"缺一个对象不等于不可能"。
7. B6 若要测记忆，不给坐标；若要测执行，才给。同一样本不混用。

**各层目标文写什么**

| 层 | 谁写 | 重点要素 |
|---|---|---|
| level0 run goal | 样本 | 目的、总约束（B4）、验收口径（B2）；不写路径，不写子目标 |
| level1 episode 目标（中期冻结表） | 样本 | 本局范围（B1）、本局完成信号（B2）、本局约束（B4） |
| level2 task | plan·L1 生成（短期冻结时为样本） | 动作级完成信号（B2）、停手（B3） |

## 三、对照实验

**问题**：同一批任务，目标文写全六个要素与只写目的，成功率差多少；哪个要素贡献最大。

**设计**

1. **只变目标文与 `success_criteria` 的措辞**，起点存档、机械判据、预算、模型、冻结层全部不变。`success_criteria` 是给 judge 的输入，不是真值，可以随臂变化。
2. **臂**：
   - 全边界：B1–B4、B6 按上节规则写全。
   - 无边界：只保留目的一句话。
   - 留一法：全边界去掉其中一个要素，共 5 臂，用来分配贡献。
3. **公平性前提**：机械判据必须接受"无边界目标文的所有合理读法"。如果无边界读法下的合理做法被判据判负，实验测的是判据苛刻度而不是边界作用。每条样本冻结时人工列出合理读法，逐条过判据。
4. **配对**：同一样本的各臂配对比较，`k_metric` 沿用样本设定，每臂至少 k = 3，长期任务因随机性大取 `pass_at_k` 并另报 `pass_hat_k`。
5. **先小后大**：中期任务建好后，用同样的方法先在中期做一轮（冻结层是 episode 目标表，边界写在 episode 目标里）；长期任务建好后（只冻结 run goal，边界写在 run goal 里）再做一轮。两档的边界要素权重预计不同，结果分开报。

**度量**

| 度量 | 含义 |
|---|---|
| 机械成功率 | 主指标 |
| 越界动作数 | `overshoot_scorer` 的"完成之后多出的动作"，对应 B3 |
| 违约率 | 违反 B4 的运行占比（如进了中心、超预算），机械检查 |
| judge 假阳 / 假阴 | 对照 judge 判定与机械判据，对应 B2 的清晰度 |
| 额外目标数 | plan 新增 / 重开的目标数（受 `plan_max_new_goals` 限制），对应 B1、B5 |
| 步数与成本 | 边界写得越全是否更省 |

**读法**：只在配对差异的置信区间不含 0 时才下结论；样本量不足时报告趋势，不外推。

## 四、不做

- 不为让对照有差异而故意把无边界目标写得含糊误导。
- 不改机械判据来迁就某一臂。
- 不在对照结果出来前把六要素写成强制规则，目前只是经验与清单。
