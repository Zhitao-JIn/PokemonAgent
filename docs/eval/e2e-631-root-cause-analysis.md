## 可下结论的边界

已定位增量在何时、哪些调用及其显式上下文；没有找到足以证实摘要删掉关键事实后导致补偿性thinking的证据。并不排除摘要改变了注意分配或其他样本存在遗漏；这里只审计了首轮相同输入及增量最大的若干路径。要确认因果需要额外控制对照；本次没有超出逐轮停下的授权开跑。
