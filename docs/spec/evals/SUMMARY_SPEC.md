# Summary 独立评测

## 范围

公开 Inspect 任务 `brain_summary`，默认 `v20261020_1846`，包含 task 41、episode 20、run 20，共 81 次冻结生产调用。只测单次蒸馏，不启动模拟器、不写记忆、不串联候选摘要形成新的上层输入。

solver 按精确信封调用生产 task_summarizer / summarizer / run_summarizer，使用 verify_model（生产摘要实际使用 verify provider）。保存解析正文、真实模型调用与失败账，不把来源章作为候选答案。

## 数据与证据边界

复用 brain_calls 的输入，独立 summary 清单冻结输入指纹和五维 rubric 字节，不复制旧模型答案，也不把旧答案当 gold。v1 请求不符合本次任务契约，显式拒绝。

评分员只读成功生产调用实际发送的 prompt、images 和候选正文，以及独立 rubric。不能额外翻原始请求里未渲染的字段、trace、其他样本或后续结果。截图沿用实际调用的裁剪、拼图与模型能力选择。

上层摘要只对可见材料负责，不能要求它恢复看不到的底层事实。若有最终定案表则以表定案；上游材料有错与本次新增幻觉分别处理。条件性建议可以新增，不能写成执行过的事实。

## Scorer

契约通过率单独机械统计：Pydantic 正文类型与范围；summary、reason、quality_rationale 非空；episode/run 的 markdown 按生产 prompt 要求非空。task prompt 未要求 markdown 非空，不额外添加硬限制。来源章不评分。解析/提供者耗尽保留 sample error，样本总数和错误数不能被合格分母隐藏。

独立 AI 调用一次，返回五个连续维度（0..1 或未知）：事实保真、关键信息保留、归因合理性、经验可复用性、内容一致性与精简。每维必须引用生产输入及候选字段。候选 quality_score 是记忆价值自评，不是 eval 分数；只核自评理由是否自洽，不按自评分值抬分。

另判重大失真：编造关键经历/结果、把未达成写为达成、无视最终定案等。其通过率与失真率明确标为模型审阅。重大失真为真时，语义通过值为 0，即使五维均分较高也不合格；为假且五维完整时为 1。此通过值只代表无重大失真且评价完整，不宣称普通质量维度全部优秀，不另设未经讨论的质量阈值。

五维均分仍原样报告，不把重大失真偷偷改成零分。任一维未知则该样本整体质量均值未知，已知单维仍可单独统计；重大失真未知时不进入通过率/失真率分母。缺项、重复维度、越界、非有限数、布尔伪装分数、空证据或无效 JSON 使整次模型评分未知，保留原因和原文；传输错误显式抛出。关闭 grader 时仅评契约，不填零质量分。

## 汇总

报告契约通过率、总体/各维有效数和均分、重大失真率及其有效数、模型审阅通过率、各层完整质量分数及数量。总体质量取三层质量均值的均值，必须三层都有完整质量评分；缺任一层则未知。逐样本均值作为另一个诊断值，不能冒充三层宏平均。

## 验证与计划

先测数据指纹与信封分派，再测未知值/重大失真/分层分母边界，最后用真实生产门面加假 provider、假评分员跑完 81 条。额外验证 grader 收到的 prompt/images 与生产账一致，参考不进入 solver，关闭 grader 不访问模型。不调用付费模型，不改变采集或生产 prompt。

## 入口

完整三层：`inspect eval evals/brain_summary/task.py`。

只评一层：`inspect eval evals/brain_summary/task.py -T layer=task`（也可 episode/run）。

只评机械契约：追加 `-T grader_model=none`；solver 仍会调用被测生产模型。`-T model=型号` 覆盖被测 verify provider，`-T grader_model=评分型号` 覆盖独立评分员。未显式指定时沿用 evals/config.json 的 verify_model 与 evaluation_models.result_grader。

质量/重大失真结论均是模型审阅，不能将假 provider/grader 的链路测试分数视为真实摘要质量成绩。

## 实现验证

2026-10-20：摘要专属测试、既有递归任务/建议式评分回归与公开登记测试共 39 passed。真实生产门面使用假视觉 provider，81 条样本完整跑通；逐条比对实际 prompt 与实际图片列表和 grader 输入，参考量表未进入 solver；候选自评 0.1 不影响假 grader 给出的 0.75。另验证重大失真不被高均分抵消、未知分母、缺层宏平均和篡改指纹拒绝。ruff check/format、文件/函数长度检查通过，旧四族数据和 brain_calls 原料目录无改动。未调用真实模型或模拟器。
