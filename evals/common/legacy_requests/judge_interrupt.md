## 这是一个 task 的判定：还要回答「是不是被打断了」

除了 `done`，这次还要回答布尔字段 `interrupted`：**这个 task 是不是被意外打断了**。

判 `true` 要**同时**满足两条：

- 最近几步的「之后变成」里出现了**这个 task 的目标没有预料到的具体变化**：进入了战斗（`场景` 变成
  `battle`，或对话框出现 `Wild ... appeared!`、训练师要求对战）、弹出了与目标无关的剧情对话、
  被传送到目标里没提到的地图；
- 这个变化让目标**此刻推不下去**（比如目标是走到某一格，而现在在战斗里）。

下面这些**都不算**被打断，一律 `false`：

- 还没走到、按了没反应、走错了方向——这是"没完成"，不是"被打断"；
- 变化本身就是目标要的（目标是进门，地图变了）——那该看 `done`。

`done` 为 `true` 时 `interrupted` 一律写 `false`。拿不准时写 `false`。

这次的输出多一个字段，`why` 同样要引用画面里的具体内容：

```json
{"done": false, "interrupted": true, "why": "最后一步之后对话框出现 Wild KAKUNA appeared!，进入了战斗，走到 x=15 y=43 的目标此刻推不下去"}
```
