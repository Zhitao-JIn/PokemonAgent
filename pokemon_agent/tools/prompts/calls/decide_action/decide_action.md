## 停滞时要换打法

如果最近几步你交出的是**相同或相似的动作**，而画面关键状态（位置、场景、对话框、光标）没有任何变化，说明这条路走不通。**必须换一种尝试方向**——换一个按键、换一个位置、或转向目标的另一条路径；把同一个动作再交一遍，只会得到同一个结果。这一条是软约束：连续原地打转会被强制结束本局，那比换错方向代价更大。

## 各字段的要求

- **action**：下面「可用按键」里的**一个**键名。

$map_guide

`known_objects` 每行是一次互动记录：**站在哪一格、按了哪个键、碰的是哪一格的什么、
结果是什么**（进入新地图 / 对话 / 无效果）。这是**已经发生过的事实**，不是参考意见——下面三条是硬规则：

- **同一格、同一个键、结果是「无效果」，就不要再按第二次。**
  同样的姿势碰同一个东西只会得到同样的结果。
  想再碰它，必须换姿势：换一格站、换一个朝向，或者换一个对象。
- 某个对象上「无效果」的记录已经有 **2 条或更多**，
  说明**你对它的判断本身是错的**——先怀疑「这是不是我要找的那个东西」，
  而不是怀疑「是不是按得不够多」。这时必须换一个做法。
- 「它就在正前方、朝向也对、中间没有障碍」是**能不能按**的理由，
  不是**按了会有用**的理由。当这套理由已经被记录里的失败推翻过一次，就不能再拿它当论据。

和上一次相比，**必须有一样东西变了**（站的位置、朝向、按的键、或者对象），
什么都没变，就是在重复一个已知无效的动作。

## 检索到的相关知识（怎么信）

按当前场景/目标从知识库（`semantic/knowledge/*.md`，运营维护、长期为真）检索出来的片段。
**检索覆盖不到当前场景是常态，不是错误**——下面写「没有检索到相关知识」，不代表这类
情况没有已知规律，只代表这次没搜到，不能因为这行字就断定「这里没有先例」。

反过来，检索到的内容本身可信，但它说的是**跨地图/跨局普遍成立的规律**（比如「门要怎么
碰」「菜单里哪个键是确认」），不是这一帧此刻发生了什么——**不能拿它替代「已知事实」里的
证据，也不能用它断言这一帧具体发生了什么**，只能用来指导「该怎么做」，不能用来判断
「现在是什么状态」。数据在下面「检索到的相关知识」一节。

## 相关记忆（怎么读）

记忆**一键一条**：`(局, step=N)` 当时看到 → 做了什么 → 之后变成。前后两份是**同样的字段、
同样的顺序**，方便你逐行对照；相邻两条里重复的那一帧只贴一次。**这是这一局自己走过的原始记录**。

**先对照，再下结论。** 把「当时看到」和「之后变成」逐个字段比一遍：

- 所有字段都一样 → **那一键没有产生任何效果**，再按一次同样会没有效果，换一个做法。
- 有字段变了 → 变的正是那一键改变的东西。只有一两个字段变也是变了：选单里移动光标，
  只有 `光标` 那一行会变。

记忆里的「因为」是**当时的自己**给的说法，不是已经验证过的结论——以「之后变成」为准。
数据在下面「相关记忆」一节。

## 跨局摘要记忆（怎么读）

这是**之前几次尝试**（不是这一局）事后蒸馏出来的经验摘要——跟「相关记忆」不是
一回事：那是这一局自己走过的原始记录，字段可以逐条核对；这里是别的局自己总结的一段话，
**可能带着那一局自己的偏差或错误结论，没法逐字段核对，可信度比「相关记忆」低**。
两边冲突时，以这一局自己实际看到的（已知事实/相关记忆）为准，这里只作参考，
不能当成结论直接采信。数据在下面「跨局摘要记忆」一节。
