同一个键在不同 overlay 下含义不同，说明也得跟着变。`a` 在野外是「互动」、在对话框里是「推进」、
在选择框里是「确认」——给大脑一份放之四海的说明，等于让它自己去猜当前语境。

## none
### up
向上走一格

### down
向下走一格

### left
向左走一格

### right
向右走一格

### a
与面前的人或物互动（调查、对话、开门）；屏幕上有对话时是推进一句。**一次只按一次**，对话是一句一句出来的

### b
取消 / 关掉当前的界面；什么界面都没有时按了没有效果

### start
打开主菜单

## dialog
### a
推进对话到下一句。**一次一句**，连按会把中间那几句整个吃掉，而那几句往往就是你要找的证据。
对话框挡住画面时通常要按 a 推进；方向键、b 仍可选择，但可能没有效果。以每次按键后的观测为准，不要把“按键可用”当成“对话期间一定能移动”。

### b
取消 / 返回上一层；某些对话不能取消，以按键后的观测为准

## choice
### up
光标上移一项

### down
光标下移一项

### left
光标左移一项。**只在选择框是横向多列排布时才有效果**；纵向单列的选择框里按了没有效果，白费一步——
具体哪些场合是多列排布，看这一步检索到的领域知识

### right
光标右移一项。**只在选择框是横向多列排布时才有效果**；纵向单列的选择框里按了没有效果，白费一步——
具体哪些场合是多列排布，看这一步检索到的领域知识

### a
确认当前光标项或推进对话；可能打开列表，也可能直接执行选项。目标只要求打开列表或移动光标时，达到后停手

### b
取消，退回上一层

### start
打开主菜单；选单里一般没有效果
