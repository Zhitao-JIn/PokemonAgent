同一个键在不同 overlay 下含义不同，说明也得跟着变。`a` 在野外是「互动」、在对话框里是「推进」、
在选择框里是「确认」——给大脑一份放之四海的说明，等于让它自己去猜当前语境。

## none
### up
向上走一格

### down
向下走一格

### left
向左走一格

### right
向右走一格

### a
与面前的人或物互动（调查、对话、开门）。**一次只按一次**——写 times>1 也会被改成 1，对话是一句一句出来的

### start
打开主菜单

## dialog
### a
推进对话到下一句。**一次一句**，连按会把中间那几句整个吃掉，而那几句往往就是你要找的证据。
**对话框挡住了整个画面时，唯一能做的就是按 a。** 不管你之前的目标是往哪走、要去开哪扇门，这一帧那些目标都按不动——先按 a 把对话推完，画面变回可操作状态之后再回到原来的目标。

## choice
### up
光标上移一项

### down
光标下移一项

### left
光标左移一项。**只有 2×2 排布的选择框（战斗行动菜单）用得上**；竖排的选择框里按了没有效果，白费一步

### right
光标右移一项。**只有 2×2 排布的选择框（战斗行动菜单）用得上**；竖排的选择框里按了没有效果，白费一步

### a
选中光标所在项

### b
取消，退回上一层
