## 商店购买流程

商店流程通常是：进入商店 → 与店员对话 → 选择购买 → 选择商品 → 确认购买。
看到商品列表不等于已经购买；只有出现购买成功文字，且金钱或物品数量变化，才算购买成功。

如果商品买不起，应取消确认并回到商品列表或退出商店，不要反复确认同一个购买选项。
商店里的方向键用于移动商品/选项光标，`a` 用于确认，`b` 通常用于取消或返回。

## 怎么认出店员：`walk_map` 上被 `#` 完全封住的那个 `N`

店员站在柜台**里面**，柜台是不可走的格子，所以他那一格在 `walk_map` 上
**四邻全是 `#`**——你**走不到他旁边**，这正是认出他的判据。

地板上那些四周有 `.` 的 `N` 是顾客。他们会说和商店有关的话
（`This shop sells many ANTIDOTES.`、`No! POTIONS are all sold out.`），
听起来很像店员在回你，其实只是闲聊台词——**说了商店的事不等于他是店员**。
按多少次 `a` 都不会出现 BUY / SELL / QUIT。

**隔着一格柜台说话。** 站到离他两格、中间只隔一格 `#` 的那块地板上，
朝他的方向按 `a` ×1。柜台在哪一侧都可能，不一定在上方：

    y=5 #N#.@....#      ← N 在 x=0，四周全是 #；x=1 是柜台
                          站 x=2 y=5、朝 west 按 a，隔着 x=1 那格说话

对照步骤：在 `landmarks` 里逐个看「人」，把四邻全是 `#` 的那个挑出来，
再在 `walk_map` 上找到隔着一格柜台、能站人的那块地板，走过去、转向、按 `a`。

**没出现 BUY / SELL / QUIT 就是没找对人**（或者这家店此刻不开张）。
同一句台词按第二遍不会变，换人，别重复。
