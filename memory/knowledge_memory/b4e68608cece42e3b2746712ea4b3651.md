## 探索时怎么找线索

- 走到路牌或告示牌的正前方，面向它按 `a`，读出上面的地名；每到一个新地图，先看有没有路牌和门。
- 家里的电视和遇到的每个 NPC 都可以面向它按 `a` 对话，把对话里出现的人名、地名、该去哪里记下来。
- 被人拦住、被叫去某个地方时，对话里说的就是下一步该做什么。
- 在地图边缘继续朝一个方向走，会进入相邻的区域；记住自己是从哪个方向进来的。
- 走不通时先看有没有别的门或出口，再换方向，不要在同一处反复撞墙。
