## 门、楼梯与地图切换

`walk_map` 里的 `D` 是门/入口/楼梯。**门只有一种成功：`map_id` 变了。** 看见门、走到门前、
站到门格上，都不等于进了门；每一步之后都看下一帧的 `map_id`。

**进门、出门一律用方向键，不用 `a`。** 在门格上或对着门按 `a` 什么都不会发生。

## 两种门

1. **走上去就切图**（多是从外面进建筑的门）：朝门格走一步，踩上去的同一拍 `map_id` 就变了。
2. **站在门格上朝外再按一次才切图**（室内出口、森林/山洞的出口、门房两头的门）：这种门格贴着
   地图边界，朝外那一侧的 `neighbors` / `walk_map` 是 `#`。走上门格时 `map_id` 不变，这是正常的——
   再朝 `#` 那一侧按一次方向键就出去了。`#` 说的是"走不过去"，不是"按了没用"：门格上的那一下
   不是走路，是开门。

所以站在 `D` 上没换图时，**先朝贴着地图边界、显示为 `#` 的那一侧按一次**，而不是按 `a`、
也不是换一扇门。一排并列的门格通常都通向同一处，从这一格横着走到隔壁那一格，走的还是原地图，
`map_id` 一个数都没变，不能把"人走到了门那一格上"当成"门开了"。

## 切图之后

切图后画面和可走的格子都换了，先看新一帧的 `where` / `walk_map` 再决定下一步，不要照着切图前的
`walk_map` 继续走。

## 已知事实里的门

`known_objects` 每行是一次碰门的记录："站在 x= y= 按 某键 → 地图N x= y= 的门：进入新地图M"
或"……：无效果"。写着「进入新地图」的，照同一格、同一个键再做一次就行；同一格同一个键写过
「无效果」的，换个方向键再试，不要原样重复。
