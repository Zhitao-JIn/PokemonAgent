## 门、楼梯与地图切换

看到门、楼梯或出口不等于已经完成进入。应先移动到入口，再根据下一帧的
`map_id`、`scene` 或地点描述确认发生了地图切换。若画面仍显示原地点，说明只是
靠近了入口或撞到了阻挡，不能把“看见门”当成“进入门内”。

进入建筑时不要连续长按太多次：过场、门口和室内的可用动作可能不同。确认地图切换后，
再决定下一步，不要根据切换前的 walk_map 继续盲走。


## 站在 `D` 格上要往哪个方向按

`walk_map` 里 `D` 是门/入口/楼梯。**室内的出口就是这么用的**：门格贴着地图边界，
`neighbors` 会告诉你那个方向是 `#`，但**按下去就出去了**——`#` 说的是"走不过去"，
不是"按了没用"，门格上的那一下不是走路，是开门。

所以站在 `D` 上没换图时，**先把四个方向里那个朝向地图边界的试一遍**，而不是换一扇门。
两扇门挨着的时候尤其要注意：从这扇门走到那扇门，走的还是屋里，`map_id` 一个数都没变，
不能把"人走到了门那一格上"当成"门开了"——门只有一种成功：`map_id` 变了。

`known_objects` 里门的档案会记"站在哪一格、按了哪个键 → 结果"：写着「已经走通」的
照做就行；写着"还剩 N 种碰法没试"（N>0）说明还没找对角度，不要换一扇门；写着
"8 种碰法全试过了"的就是打不开（剧情没到，或者是装饰）。
