## 战斗中的行动选择

战斗行动菜单中的 `FIGHT`、`PKMN`、`ITEM`、`RUN` 是不同分支，不能把方向键移动光标
和 `a` 确认混成一次野外移动。选择 `FIGHT` 后要重新读取招式列表；选择 `PKMN` 后
要确认切换对象；选择 `ITEM` 后要确认道具列表。每次分支切换都应以新画面为依据。

野生战斗可以尝试 `RUN`，但逃跑可能失败；出现失败文字仍是一次有意义的结果，不能
继续重复同一个动作而不重新观察。

### 行动菜单是 2×2，不是竖着的四行

**这是最常犯的错。** 战斗行动菜单的四个选项排成两行两列：

```
FIGHT   PKMN
ITEM    RUN
```

`FIGHT`=左上，`PKMN`=右上，`ITEM`=左下，`RUN`=右下。光标开局在 `FIGHT`。

所以：
- 到 `PKMN`：`right`
- 到 `ITEM`：`down`
- 到 `RUN`：`down` + `right`（两下，顺序无所谓）

**不要把它当成竖排列表按 `down×3` 去够 `RUN`。** 那样光标只会在左列
`FIGHT`↔`ITEM` 之间动，按 `a` 打开的是道具袋，不是逃跑——而且画面看着"确实
换了个界面"，很容易被当成成功。选项的编号顺序（0=FIGHT 1=PKMN 2=ITEM 3=RUN）
是**读出来的顺序**，不是屏幕上的方向，别拿索引差当按键次数。

### 但下一层菜单是竖排的

进入 `FIGHT` 后的招式列表、`ITEM` 的道具袋、`PKMN` 的队伍列表，都是**竖着一行
一个**，用 `up`/`down` 移动。**只有最外层那个行动菜单是 2×2。**
换层之后要重新按新画面的排布来数，不要沿用上一层的按键方式。
