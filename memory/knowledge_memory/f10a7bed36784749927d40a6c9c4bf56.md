## 宝可梦中心治疗

进入宝可梦中心后，不要沿野外路线继续移动；先观察室内布局并找到护士。治疗需要
面向护士并推进对话，看到治疗完成或队伍恢复的证据才算成功。

治疗完成后，若任务要求离开中心，应从室内出口返回野外并确认 `scene` 或 `map_id`
发生变化。看到护士不等于已经治疗，看到治疗动画也不等于已经离开中心。

### 护士在哪：`walk_map` 上被 `#` 完全封住的那个 `N`

护士站在柜台**里面**，柜台是不可走的格子，所以她那一格**四邻全是 `#`**——
你**走不到她旁边**，这正是认出她的判据。地板上那些四周有 `.` 的 `N` 是住客，
对他们按多少次 `a` 都不会开始治疗。

**隔着一格柜台说话。** 站到离她两格、中间只隔一格 `#` 的那块地板上，
朝她的方向按 `a` ×1。宝可梦中心的柜台通常在上方（她在你正上方两格，
中间那格是柜台），但商店/柜台在左侧的布局也有，**按"被 `#` 封住"来找人，
不要按方位来找**。

对照步骤：在 `landmarks` 里逐个看「人」，挑出四邻全是 `#` 的那个；
在 `walk_map` 上找到隔着一格柜台、能站人的地板；走过去、转向、按 `a`。

**地图 41 是初心镇的宝可梦中心**，不是研究所（研究所是地图 40）。
如果记忆里有"地图 41 是实验室"这类说法，那是过去某一局自己编出来的结论，
不要采信——用上面的几何特征重新找一遍。
